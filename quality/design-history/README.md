# Design history file index

The [controlled record index](../../docs/quality/design-record-index.csv) maps
AirTon's intended use, requirements, risks, design decisions and verification/
validation records. It is the current evidence index, not a certified DHF.

Record clinical/design approvals, review minutes, input/output revisions,
bench/calibration traces, study permissions/results and design transfer when
they exist. Draft records remain draft and unrecovered artifacts remain open.
[Quality-system process](../../docs/quality/quality-system.md) governs this work.
