# Mechanical source files

Add native parametric CAD plus dated neutral exports and drawings after design.
Required: alignment datums, working-distance controls, operator positioning,
inter-pupillary adjustment concept for bilateral operation, cleanable interfaces,
protected air path, battery access, tolerance stack and revision record.

Use `revision/part-name.native-extension`; record tool version, units, owner,
reviewer, manufacturing status and export hashes in the artifact manifest. No
STL/STEP or production drawing is supplied or implied by this repository.
