# Optical feasibility specification

## Decision to resolve

Can the selected optical path resolve a reproducible corneal/model-surface event
that supports pressure inference within an approved uncertainty budget?

Compare reflection/applanation detection, high-speed imaging and the deck's
interference hypothesis on shared fixtures. Document source spectrum/power,
geometry, working distance, detector bandwidth, digitization, timestamp source,
illumination exposure and physical tolerances. All numeric human-exposure limits
require specialist review; none is defined by this document.

## Experiment records

For each fixture condition record independent reference pressure/uncertainty,
material and geometry, calibration IDs, delivered stimulus trace, optical trace,
alignment displacement, clock offsets, environment, operator, repetitions, and
all acquisition failures. Include blocked/ambient-light-only controls to determine
whether a measured event comes from the intended path.

An interference experiment additionally needs reference/sample path diagrams,
coherence assumptions, phase/amplitude retrieval, unwrap failure handling, a
displacement reference, and whole-surface-motion controls. Do not equate the
visibility of fringes with pressure accuracy.

## Go/no-go review

An optics and biomedical engineering reviewer must approve the signal definition,
timing error budget, light-hazard approach and measured repeatability. Down-select
using information quality, failure modes, calibration transfer, power, recurring
cost and maintainability. Record why rejected approaches failed and preserve raw
data under an experiment manifest. Clinical agreement is a later gate.
